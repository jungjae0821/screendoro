# 고정 규칙 (house-rules)

screendoro 사용자가 **모든 프로젝트**에 적용하는 화면 규칙이다. 1·3단계에서 화면에 반영하고, 4단계에서 위반을 찾아 고친다.

우선순위: 사용자 지시 > **이 문서** > 프로젝트 `DESIGN.md` > 다른 `references/` 문서 > `frontend-design`·`impeccable` 기본값.
`DESIGN.md`나 `landing-visual-preset.md`가 이 문서와 다르면 이 문서를 따른다. `DESIGN.md`에 이유가 적혀 있어도 마찬가지다.

---

## 1. 폰트: 경기천년체

- 화면의 모든 글자는 경기천년체로 쓴다.
  - 제목, 버튼, 내비게이션, 강조 문구: **경기천년제목** (Light / Medium / Bold)
  - 본문, 설명문, 표, 폼 입력값: **경기천년바탕** (Regular / Bold)
- 숫자·코드처럼 고정폭이 기능상 꼭 필요한 곳만 예외로 고정폭 폰트를 쓸 수 있다.
- 폴백: `'경기천년제목'`(또는 `'경기천년바탕'`) 다음에 `'Pretendard', system-ui, sans-serif`를 둔다.
- 폰트 파일:
  - 프로젝트에 이미 폰트 파일이나 확인된 웹폰트 주소가 있으면 그것을 쓴다.
  - 없으면 사용자에게 파일을 받는다. 웹폰트 CDN 주소를 지어내지 않는다.
  - 파일을 구하지 못했으면 `font-family` 선언과 폴백만 넣고, 완료 보고에 "경기천년체 파일 미적용"이라고 적는다.
- 한국어 본문에는 `word-break: keep-all`을 함께 쓴다.

## 2. 버튼: 둥근 모서리

- 모든 버튼(`button`, 버튼 모양 링크, `input[type=submit]` 등)은 모서리가 둥글어야 한다. 각진 버튼(반경 0~7px)은 쓰지 않는다.
- 반경은 **8px 이상**. `DESIGN.md`에 버튼 반경 값이 있고 8px 이상이면 그 값을 쓴다. 정해진 값이 없으면 높이의 절반(알약형)을 쓴다.
- 한 화면 안의 버튼은 같은 반경 규칙을 따른다. 버튼마다 반경이 제각각이면 안 된다.

## 3. 이중 테두리 금지

선이 두 겹으로 보이는 처리는 모두 금지다.

- `border-style: double`
- 테두리가 있는 요소에 `outline`이나 테두리 역할의 `box-shadow`(블러 0, 퍼짐 1px 이상인 그림자)를 겹친 것
- 테두리가 있는 요소 안에 테두리가 있는 요소를 바짝 붙여 넣은 것 (카드 안 카드, 테두리 상자 안 테두리 입력창 등). 안쪽과 바깥 테두리 사이 간격이 16px 미만이면 이중 테두리로 본다.
- 테두리 + 안쪽 그림자(`inset`)로 선을 하나 더 만든 것
- 테두리 바로 바깥이나 안쪽에 선 역할을 하는 가상 요소(`::before`, `::after`)를 덧댄 것

고치는 법: 둘 중 하나만 남긴다. 기본은 **안쪽 테두리를 지우고** 간격이나 면 색으로 구분한다.

예외: 키보드 포커스 링(`:focus-visible`)은 접근성 요구사항이라 지우지 않는다. 대신 포커스 링이 다른 선과 겹쳐 세 겹이 되지 않게 `outline-offset`을 준다.

## 4. 불필요한 밑줄과 요소 금지

목적 없는 장식은 넣지 않는다. 아래는 넣지 않고, 있으면 지운다.

**밑줄**
- 제목, 섹션 제목 아래 장식 밑줄이나 짧은 강조 막대
- 내비게이션, 버튼, 카드 제목 링크의 밑줄
- 강조하려고 단어 아래 긋는 형광펜·물결 밑줄
- 제목 아래, 섹션 사이의 구분선 중 레이아웃상 필요 없는 것

예외: **본문 문장 속 링크**는 색만으로 구분하면 접근성 위반이다. 밑줄을 남기거나 굵기 같은 색 이외의 표시를 둔다.

**요소**
- 제목 위 작은 라벨(eyebrow), 의미 없는 배지·태그
- 내용과 상관없는 장식 아이콘, 모든 제목 앞에 붙인 아이콘
- 배경의 흐릿한 원형 블롭, 장식용 점·격자 패턴, 의미 없는 그라디언트 면
- 내용이 같은 말을 반복하는 보조 문구, 기능 없는 빈 카드나 자리표시자
- 클릭되지 않는 화살표, 동작하지 않는 "더 보기" 같은 장식성 컨트롤

판단 기준: "이걸 지우면 사용자가 정보나 기능을 잃는가?" 잃지 않으면 불필요한 요소다.

## 5. 4단계 점검 절차

antislop 점검과 같은 시점에 한다. 이 문서의 위반은 모두 **필수** 항목이다.

1. **코드 검색**: 만든 화면의 스타일과 마크업에서 아래를 찾는다.
   - `double`, `outline:`, `box-shadow`(블러 0 퍼짐 있는 것), `inset`
   - `underline`, `text-decoration`, `border-bottom`, `::after`, `::before`
   - 버튼 스타일의 `border-radius`(또는 `rounded-none`, `rounded-sm`, `rounded`)
   - `font-family`(경기천년체가 아닌 폰트)
2. **렌더링 검사**: `render-check.md` 순서로 화면을 띄운 뒤, 폭마다 `references/house-check.js` 내용을 `javascript_tool`에 그대로 넣어 실행한다. 읽기만 하고 페이지를 바꾸지 않는다. 결과의 각 목록이 비어 있어야 통과다.
3. **눈으로 확인**: 스크립트는 "불필요한 요소"를 다 잡지 못한다. 캡처를 보고 4절 목록에 해당하는 것이 있는지 확인한다.
4. **수정**: 위반은 지우는 쪽으로 고친다. 이중 테두리는 한 겹만 남기고, 불필요한 밑줄과 요소는 삭제한다. 폰트와 버튼 반경은 규칙 값으로 바꾼다.
5. **재점검**: screendoro 4단계 재점검(1회)에 포함해 고친 화면만 다시 확인한다.

## 체크리스트

- [ ] 모든 글자가 경기천년제목·경기천년바탕 (예외는 고정폭이 필요한 곳뿐)
- [ ] 경기천년체 파일이 실제로 로드됨 (못 했으면 보고에 "미적용")
- [ ] 모든 버튼 반경 8px 이상, 화면 안에서 같은 규칙
- [ ] 이중 테두리 없음 (포커스 링 예외)
- [ ] 장식 밑줄 없음 (본문 속 링크 예외)
- [ ] 불필요한 장식 요소 없음
