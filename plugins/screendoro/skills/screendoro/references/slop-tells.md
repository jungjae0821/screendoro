# 생성 전에 피할 것 (slop-tells)

screendoro 2단계(시안을 그리기 전)와 3단계(화면 코드를 쓰기 전)에 읽는 문서다. 4단계 antislop 점검에서 잡을 것을 **만들기 전에** 피하려고 둔다. 이 세션에서 이미 읽었으면 다시 읽지 않는다. 대화가 요약돼 본문이 보이지 않으면 다시 읽는다.

출처: `frontend-design`의 "AI 디자인이 몰리는 유형"과 `antislop-ui`의 징후 목록을 한국어로 줄여 옮겼다. 원문이 바뀌면 원문을 따른다. 4단계에서는 지금처럼 antislop 스킬 원문으로 다시 점검한다.

우선순위는 `SKILL.md`와 같다. 사용자가 직접 고른 방향(프리셋 포함, 사용자가 말로 정한 색·배치)이 아래 유형에 해당하면 사용자 쪽을 따른다. 이 문서가 막는 것은 **AI가 고른 기본값**이다.

---

## 1. AI 디자인이 몰리는 다섯 유형

아래는 주제와 상관없이 나오는 기본값이다. 사용자가 정하지 않은 축에서는 이것을 고르지 않는다. 시안 방향 후보(`design-setup.md` 3절)에서도 뺀다.

1. **크림 + 세리프 + 테라코타**: 따뜻한 크림 바탕(#F4F1EA 근처), 대비 큰 세리프 제목, 테라코타·흙빛 강조색(#D97757 근처). 경기천년바탕이 세리프라서 이 유형으로 끌려가기 쉽다. 바탕이 크림이면 이미 절반은 이 유형이다.
2. **검정 + 형광 강조 하나**: 거의 검정인 바탕에 형광 초록이나 주홍 강조색 하나.
3. **신문 지면형**: 가는 선, 모서리 0, 빽빽한 단. 신문·잡지 편집 디자인을 흉내 낸 배치.
4. **SaaS 카드 세트**: 내용을 같은 크기 둥근 카드로 잘라 반복, 위계와 상관없이 모든 요소에 같은 반경, 카드마다 같은 옅은 회색 그림자, 장식용 그라디언트 면.
5. **템플릿 장식**: 제목마다 위에 붙은 대문자·넓은 자간 라벨, 가운뎃점으로 이은 메타 문자열(`A · B · C`), `단어 — 조각` 형식 라벨, 순수 검정 대신 쓴 살짝 색 섞인 검정(#0B0B0B, #111), 작은 데이터 라벨에 쓴 고정폭 폰트, 링크·버튼 글자 끝의 `→`.

## 2. 생성 전에 피할 징후

이유 없이 손이 가면 다시 설계한다. `house-rules.md`가 이미 금지한 것(eyebrow, 블롭, 장식 밑줄, 이중 테두리 등)은 여기 다시 적지 않았다.

**색과 면**
- 파랑→보라, 파랑→청록, 보라→분홍 그라디언트를 주색으로 쓰기. 페이지 전체에 번지는 색 후광
- 내비게이션, 카드, 모달, 사이드바에 동시에 블러·유리 효과
- 모든 컴포넌트에 큰 그림자를 달아 페이지 전체가 떠 보이기. 카드·버튼·아이콘·테두리에 동시에 glow
- 배경의 격자, 모눈, 점 패턴, 설계도 선
- "기술 느낌"을 내려고 고른 다크 모드
- 체계 없이 5~7색. 또는 강조색 하나를 버튼·아이콘·배지·선·배경에 전부 칠하기
- 반대쪽 극단: 흰 바탕 + 옅은 회색 테두리 + 작은 반경 + 질감 없음. 아무 개성 없는 기본 화면도 슬롭이다

**배치와 컴포넌트**
- 히어로 → 부제 → CTA 2개 → 스크린샷 → 기능 그리드 → 후기 → FAQ → CTA → 푸터를 늘 같은 모양으로 쌓기
- 크기, 높이, 아이콘, 여백이 모두 같은 기능 카드 반복
- 크기가 다른 카드를 타일처럼 채운 벤토 그리드
- 모든 섹션의 여백과 간격이 같음. 모든 섹션이 "가운데 제목 + 부제 + 같은 카드 그리드"
- "사용 방법"을 늘 둥근 아이콘 + 1·2·3 + 짧은 글 세 단계로
- 히어로 바로 아래 고객사 로고 줄
- 가운데 요금제만 "가장 인기" 배지로 강조한 3단 가격표
- 제품 이름·카테고리만 바꾼 4열 푸터(제품 / 회사 / 자료 / 법적 고지)
- 내용이 필요해서가 아니라 "AI 랜딩에는 늘 있으니까" 넣은 섹션

랜딩 전략(`landing-strategy.md`)의 섹션은 **담을 정보**이지 정해진 생김새가 아니다. "장점 3~5개"를 같은 카드 3개로, "사용 방법 3단계"를 아이콘 + 1·2·3으로 그리라는 뜻이 아니다. 섹션의 형식은 `DESIGN.md`의 방향에서 정한다.

**장식**
- 반짝임, 별, 번개, 마법봉, 다이아몬드, 큐브, 로봇, AI 구슬 아이콘
- 거의 모든 버튼에 붙인 `→`, `↗`
- 카드, 목록 줄, 섹션 제목 왼쪽의 얇은 색 막대
- "AI Powered", "Beta", "New" 알약 배지. 아무것도 표시하지 않는 반짝이는 점
- 큰 고정폭 제목, 넓은 자간의 대문자 라벨
- 신호등 점이 달린 가짜 터미널 창을 히어로나 기능 그림으로 쓰기
- 제품과 상관없는 3D 캐릭터·무료 일러스트

**모양**
- 버튼뿐 아니라 입력창, 카드, 배지, 모달까지 모두 알약 모양. 고정 규칙이 정한 것은 **버튼**의 반경이다. 다른 요소까지 같은 반경으로 맞추지 않는다. 반경은 위계를 나누는 도구로 쓴다.

**앱·대시보드**
- 화면이 무엇을 위한 것인지 묻기 전에 고른 기본 틀: 왼쪽 사이드바, 상단 바, 숫자 카드 4개, 차트 하나, 표 하나
- 8개 넘는 같은 모양 메뉴 줄, 활성 상태는 살짝 진한 색뿐
- 지어낸 숫자 카드(12,483 / 94.2% / +12% 이번 주)
- 이름만 바꿔 반복한 활동 피드, 질문 없이 빈자리를 채운 차트, 내용과 상관없는 "이름 / 상태 / 날짜 / 동작" 열
- John Doe, 홍길동, example@example.com 같은 채움 데이터
- "데이터가 없습니다" + 일러스트, 맨 스피너

**모션**
- 사용자 동작 없이 계속 맥박 치거나 떠다니는 요소
- 모든 섹션에 같은 아래에서 올라오는 등장 효과. 여러 효과(올라오기 + 나타나기 + 떠다니기 + 커지기)를 겹치기
- 모션은 화면에 의도한 순간 하나, 그리고 사용자 동작에 답하는 움직임만

## 3. 점검 질문

`SKILL.md` 2단계 시안 방향과 3단계 계획·자기 비평에서 쓴다.

1. 비슷한 다른 제품의 화면을 요청받았어도 똑같이 만들었을까? 그렇다면 그 부분은 이 제품을 위한 선택이 아니다.
2. 1절 다섯 유형 중 하나에 해당하는가? 사용자가 고른 것이 아니면 한 축 이상을 제품 주제 쪽으로 옮긴다.
3. 2절 징후 중 해당하는 것이 있는가?
4. 이 화면에서 기억에 남을 요소는 무엇인가? 하나도 없으면 그것도 실패다. 장식을 지우기만 하면 밋밋한 기본 화면(2절 "색과 면"의 마지막 항목)이 된다.
5. 기억에 남을 요소가 여러 개면 하나만 남기고 나머지는 조용하게 만든다. 집을 나서기 전에 액세서리 하나를 뺀다.

고칠 때는 **지우기만 하지 않는다.** 뻔한 처리를 지운 자리에는 `DESIGN.md`의 방향에서 나온 처리(크기·굵기 대비, 정렬, 여백 리듬, 면 나누기, 실제 콘텐츠)를 넣는다.
